Backend

FlexRadio gets per-slice entries, SO2R TX-follow and amplifier-aware power. Everything else goes through a rigctld daemon — one rig, one entry. rigctld ships with hamlib and comes bundled with WSJT-X.

FlexRadio

The TX follower mirrors whichever slice currently holds the transmitter — select it in Wavelog and it tracks SO2R on its own. Leave blank to disable.

Amp output is logged whenever the Power Genius is out of standby; the radio's drive power is logged when it isn't. ADIF wants a nominal figure, so this is a number you set, not a live sample.

rigctld

Start the daemon for your rig first, e.g. rigctld -m 229 -r COM4 for an Elecraft K4. The name is how the rig appears in Wavelog's radio dropdown.

Wavelog

Token is stored but never displayed. Leave blank to keep the current one. Must be a v2 token (wl2_) with the radio:write scope — plus qso:write if WSJT-X forwarding is on.

The station profile ID is the number in the URL when editing the profile in Wavelog — QSOs are filed under it.

Publishing

Unchanged state is resent every heartbeat so Wavelog doesn't mark the radio stale; the interval floor keeps fast tuning from hammering the API.

QSO forwarding

Match WSJT-X's Settings → Reporting → UDP Server (default 127.0.0.1:2237). Multiple WSJT-X instances can all send to the same port — SO2R just works. QSOs that can't be delivered are spooled to disk and retried, so a Wavelog outage never loses a contact.
